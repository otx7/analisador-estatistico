## Sobre o programa

O projeto consiste em uma aplicação de linha de comando (CLI) desenvolvida
em Python para realizar análises de estatística descritiva.

O programa permite inserir os dados manualmente pelo terminal ou carregar
os dados através de um arquivo CSV.

O programa realiza três tipos de análise:

1. Dados não agrupados;
2. Dados agrupados sem intervalo de classe;
3. Dados agrupados com intervalo de classe.

São calculadas medidas como média, mediana, moda, quartis, decis e percentis.

## Como executar

É necessário ter o Python 3 instalado.

Execute o arquivo:

python analisador_estatistico.py

Depois escolha uma das opções apresentadas pelo programa:

1. Inserir dados pelo terminal;
2. Carregar um arquivo CSV.
